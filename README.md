# Self-development projects

A home for smaller things I've built, experiments I've tried, and ideas I wanted to learn from.

## RE:WEB

A Chrome and Firefox extension that opens ordinary Google searches in the Web results tab. It has a simple pause switch, optional spelling help, and an interface inspired by early-2000s console menus. Available in English and Japanese.

**Status:** v0.3.0 RC1 (development build). Automated browser checks have passed; live Google and dictionary testing still need manual verification.
